# The API's dependency manifest for Vercel, beside the entrypoint.
#
# Self-contained on purpose. It used to be `-r ../requirements-api.txt`, and
# Vercel's requirements parser refuses an include that leaves this directory
# ("Failed to parse ... Error parsing included file"), so the build failed.
#
# The pins are exactly those of the repository's `requirements-api.txt` -- the
# same seventy packages at the same versions, nothing from the dashboard. The
# `--hash` lines are not repeated: Vercel converts this file with uv's parser and
# keeps only the `==` pins anyway. Artefact verification by hash is the Docker
# image's `--require-hashes` install of `requirements-api.txt`.
#
# Two lists of one lock could drift, so they may not:
# `tests/integration/test_deployment_manifests.py` fails if any package or
# version here differs from `requirements-api.txt`. After regenerating the lock,
# regenerate this list from it.
